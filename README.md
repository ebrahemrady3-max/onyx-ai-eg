## 📌 نظرة عامة

**Onyx AI Egypt** هي منصة إدارة مشاريع ذكية، عربية بالكامل، مصممة خصيصًا لتلبية احتياجات الشركات الصغيرة والمتوسطة والمؤسسات في السوق المصري والشرق الأوسط.

المنصة تدمج بين:
- ✅ إدارة المشاريع المتقدمة
- ✅ إدارة المهام والفريق
- ✅ لوحات Kanban و Scrum
- ✅ مخططات Gantt التفاعلية
- ✅ تقارير وتحليلات ذكية
- ✅ تكامل مع الذكاء الاصطناعي
- ✅ توطين عربي كامل 100%
- ✅ دعم الاستضافة الذاتية (Self-hosted)
- ✅ واجهة مستخدم بديهية وسهلة

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- PostgreSQL 14+
- Redis 7+
- Docker (اختياري)

### التثبيت المحلي

```bash
# استنساخ المستودع
git clone https://github.com/ebrahemrady3-max/onyx-ai-eg.git
cd onyx-ai-eg

# تثبيت الاعتماديات
npm install

# إعداد متغيرات البيئة
cp .env.example .env.local

# تهيئة قاعدة البيانات
npm run db:setup

# تشغيل خادم التطوير
npm run dev
```

زيارة: `http://localhost:3000`

## 🛠️ Stack التقني

### Frontend
- **Next.js 14** - إطار عمل React
- **React 18** - مكتبة الواجهات
- **TypeScript** - لغة برمجة محسّنة
- **Tailwind CSS** - تصميم استجابي
- **shadcn/ui** - مكونات أنيقة

### Backend
- **NestJS** - إطار عمل API
- **PostgreSQL** - قاعدة بيانات
- **Redis** - ذاكرة التخزين المؤقت
- **Prisma** - ORM
- **WebSocket** - تحديثات فورية

### DevOps
- **Docker** - تطبيق الحاويات
- **Docker Compose** - تنسيق الخدمات
- **GitHub Actions** - التطوير المستمر
- **Vercel/Railway** - النشر
